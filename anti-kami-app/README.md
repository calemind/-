# アンチ神アプリ

「Game」「Social」のようなグループを作り、**グループに属する全アプリの合計使用時間**に
1日の上限（例: 30分）を設けるAndroidアプリです。

個別制限だと「1つ30分 × 10アプリ = 5時間」になってしまう問題を解決します。
すべて端末内で完結し、通信は一切行いません。

## スマホだけでビルドする手順

1. GitHubで新しいリポジトリを作成（Public/Privateどちらでも可）
2. 「Add file」→「Create new file」で、上記のファイルを同じパス・同じ名前で1つずつ作成
   （ファイル名欄に `app/src/main/java/com/example/antikami/App.kt` とスラッシュ込みで
   入力すると、フォルダも自動で作られます）
3. すべて作り終えると GitHub Actions が自動でビルドを開始
4. 「Actions」タブ → 最新の実行 → 下部の **Artifacts** から `app-debug.apk` をダウンロード
5. スマホでAPKを開いてインストール（「不明なアプリのインストール」を許可）

## 初回セットアップ（アプリ起動後）

アプリを開き、上から順に3つの権限を許可します。

1. **使用状況へのアクセス** — 各アプリの使用時間を読み取るため
2. **他アプリの上に重ねて表示** — ブロック画面を出すため
3. **ユーザー補助** — 前面に来たアプリを検知するため
   （一覧から「アンチ神アプリ」を選んでオンにする）

そのあと「＋ グループを追加」でグループ名を入力し、
「アプリ選択」で対象アプリにチェック、「時間」で上限を設定します。

## 動作の仕組み

- 使用時間は `UsageStatsManager` の**イベント履歴**から算出（毎日0時に自動リセット）
- アプリが前面に来た瞬間、および15秒ごとに合計時間をチェック
- 上限に達していたら**ホーム画面へ戻し**、警告オーバーレイを4秒間表示
- 残り5分を切ると、そのグループに入った時にトーストで通知

## 解除方法

設定 → ユーザー補助 → アンチ神アプリ をオフにするか、アプリをアンインストールします。
（あえて手間がかかるようにしています）

## 調整したいとき

- **チェック間隔**：`GuardService` の `handler.postDelayed(this, 15_000L)` の数値（ミリ秒）
- **警告を出す残り時間**：`if (leftMin <= 5 ...)` の `5`
- **ブロック画面の表示秒数**：`handler.postDelayed({ removeOverlay() }, 4000L)` の `4000`

## 注意

- ユーザー補助を使うアプリはGoogle Playの審査が非常に厳しいため、
  一般公開は想定せず、自分用にサイドロードして使う前提です。
- 端末によっては、省電力設定でユーザー補助サービスが停止されることがあります。
  効かなくなった場合は、設定でバッテリー最適化の対象外にしてください。
